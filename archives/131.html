Gmail的工具插件

2008年2月1日 | 分类: 应用 | 评论: 0 | 浏览:

所谓“道高一尺，魔高一丈”，Gmail再强，也强不过我们的Hacker们！看了下面这篇文章之后我才知道什么叫山外山、人外人了，原来自己的那些技巧还不够给人家系鞋带的：

FIREFOX 扩展

Gspace - 让你的Gmail变成一个在线存储工具

Gmail Search Extension - 在firefox搜索栏添加Gmail搜索

GcalQuickTab - 用快捷键在Gmail和Google Calendar之间快速切换。

GTDInbox - 把你的帐户变成一个功能强大的To-Do管理工具(GTD = Getting Things Done)

GMail Manager - 在浏览器中管理多个Gmail帐户

DragDropUpload - 直接拖动文件即可给邮件添加附件
CustomizeGoogle - 去除Gmail广告，强制使用https登录（这对中国用户倒是很实用），隐藏烦人的垃圾邮件计数器等等

GmailSkinz - 给Gmail换上漂亮的皮肤

Google Toolbar with Gmail search - 这个官方的工具栏当然是不可少的

E-Mail Notifier Toolbar | Gmail Notifier - 邮件提醒

_

GREASEMONKEY SCRIPTS

 Gmail Super Clean - 给Gmail改头换面

Gmail Spam-count Hide - 隐藏垃圾邮件计数器

GMail Attachment Icons - 对不同附件类型会显示不同的图标，让你一目了然，
Google Reader Integration - 在Gmail中整合Google Reader

GmailTo - 强制所有 ‘mailto’ 链接使用Gmail打开

Saved Searches - 在侧边预设搜索关键词

Conversation Preview - 不用打开邮件就可以快速预览

Google Calendar Integration - 把Google Calendar整合到Gmail里

Label Colors - 让你的标签变得五彩缤纷

Gmail Macros - 给Gmail添加额外的快捷键(例如 “t” =转到垃圾箱, “r” =标记为已读, “p’’ =标记为已读并且存档…等等).

SSLGoogle - 强制让Gmail、Docs、Calendar等页面使用https打开

GmailDrive - Gmail网络硬盘

Gmail ToDo - 小巧的To-do任务管理软件

桌面提醒器: GMail Notifier(官方的), GTray (Win XP版), GCount (Mac版), Gmail+Growl 2.0 (GmailNotifier优化插件)

GMail for Mobile - 移动版Gmail

GmailFS - 把Gmail作为存储媒介的Linux文件系统

Google Talk - 我天天开着Google Talk就是为了用它的邮件提醒功能
You’ve Got Gmail - Trillian的Gmail插件

技巧和HACKS

Unbl0ck - 如果你的公司或学校封了Gmail，那么它就可以大显身手了

Gmail icon generator - Gmail邮件图标生成器

Gmail To Thunderbird - 使用Thuderbird收取Gmail的教程

Shortcut List - Gmail快捷键大全

Hotmail Contacts Import - 如果把Hotmail的联系人导入到Gmail

Gmail trick - 找出是哪个网站泄露你的邮件地址
